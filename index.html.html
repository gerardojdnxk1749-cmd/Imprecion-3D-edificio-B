¿Cómo subir este archivo a GitHub Pages gratis en 2 minutos para que el QR abra el 3D? (Clic aquí)
  1. Guarda este código en tu computadora con el nombre exacto index.html.
  2. Entra a github.com, crea un repositorio público llamado edificio-b-ar y sube el archivo index.html (Add file → Upload files → Commit changes).
  3. Ve a Settings → Pages, en Branch selecciona main y haz clic en Save.
  4. Copia el enlace generado (https://tu-usuario.github.io/edificio-b-ar/?vista=3d), pégalo arriba y vuelve a imprimir o escanear el QR.

Requerimientos para la Creación del Objeto AR

  • Diseño del código QR impreso: Código QR estándar ISO/IEC 18004 de alto contraste (blanco y negro con zona de silencio y corrección de errores nivel M) para lectura inmediata en cualquier smartphone.
  • Modelado 3D del Edificio B: Estructura arquitectónica real de dos pisos (Planta Baja y Primer Nivel) en verde bosque institucional y blanco, con entrada principal central de doble altura, dos salidas laterales y rotulación oficial del CU UAEM Valle de Teotihuacán.
  • Información académica integrada: Ficha de identificación del estudiante y descripción sintética de la carrera Ingeniería en Computación (ICO).

Requerimientos para la Visualización en Celular

  • Dispositivo móvil: Smartphone con cámara trasera funcional, navegador actualizado (Chrome / Safari) y conexión a internet.
  • Iluminación y distancia: Luz uniforme sin reflejos intensos sobre el papel impreso; mantener una distancia de 20 a 45 cm entre la cámara y el código QR.
  • Alojamiento Web HTTPS: Publicación del archivo index.html en GitHub Pages, Vercel o Netlify para acceso directo desde el enlace del QR.

Descripción de Carrera ICO

Ingeniería en Computación (ICO)

La Ingeniería en Computación forma profesionistas capaces de diseñar, implementar, administrar y optimizar soluciones tecnológicas integrales mediante el dominio de:

  • Ingeniería de Software: Desarrollo de aplicaciones, arquitectura de sistemas, bases de datos y calidad de software.
  • Hardware y Sistemas Embebidos: Arquitectura de computadoras, microcontroladores, sensores y electrónica digital aplicada.
  • Redes de Computadoras: Conectividad, protocolos, infraestructura distribuida y seguridad informática.
  • Interacción Hombre-Máquina (IHM): Interfaces centradas en el usuario, usabilidad, accesibilidad y Realidad Aumentada / Extendida.
